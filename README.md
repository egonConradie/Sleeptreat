# Sleep Treat website

A responsive, multi-page product showcase built with semantic HTML, modern CSS and vanilla JavaScript.

## Run locally

1. Install Node.js 20.19 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address shown in the terminal.

Use `npm run build` to create the production files in `dist/`.

## Pages

- `index.html` — homepage
- `shop.html` — product showcase
- `gallery.html` — editorial gallery
- `contact.html` — validated demonstration contact form

The team is presented on the homepage at `index.html#meet-the-team`.

## Before public launch

- Confirm the full ingredient statement, allergen declaration, storage guidance, shelf life and price.
- Confirm the retail price; the website currently reserves the price position without showing placeholder copy.
- Confirm photography credits or consent for the supplied project and team images.
- Supply the website developer credit if one should appear publicly.
- Connect the contact form to an approved form service.
- Review the packaging claim “HIGH IN MAGNESIUM” against the final verified formulation and applicable rules before public deployment.
